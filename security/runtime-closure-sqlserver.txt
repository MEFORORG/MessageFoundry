# carries, transitive dependencies included, with NO other extra and NO development toolchain.

# This file is the denominator for the `sqlserver` section of docs/RISKY-COMPONENTS.md (BACKLOG
# #1955). It is the core closure in security/runtime-closure-core.txt plus what the extra adds, and
# the page classifies only those additions; the core closure's own names are classified above them.
#
# Each line below is a copy of a pin line in docker/locks/requirements-sqlserver.lock. That file is
# `uv export --no-emit-project --no-dev --extra sqlserver` of uv.lock, and the DEP-1 gate in
# security.yml fails when it differs from a fresh export. Lines are name==version, lowercase and
# sorted, with markers and hashes dropped. tests/test_risky_component_designation.py holds this copy
# to that lock in every name and version. A version edited here by hand changes nothing that
# installs, and the test refuses it.
#
# The Microsoft ODBC Driver 18 for SQL Server, which the extra also needs, is an operating-system
# package with no pip name, so it cannot appear here. The page assesses it in prose.
#
# Regenerate after the lock moves (the same command rewrites the core closure too):
#     python scripts/security/runtime_closure.py
#
