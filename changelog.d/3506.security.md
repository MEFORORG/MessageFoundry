- **The CRL signature check at start keeps a proof it has reached, and the reload warns before a
  restart that would fail.** A `bad_signature` refusal for a CRL file not yet in effect now carries
  `start_refuses` and says when a start stops refusing the file, as a `restart` refusal does. If the
  check fails part way through a file, a CRL it already proved badly signed still refuses the start;
  before, the whole judgment was dropped with an ERROR and that CRL loaded. Where warnings are
  errors, a listed CA whose serial number is not positive, as at least some system roots have, is
  now skipped alone instead of ending the check. A CRL issuer name quoted in a message is cut to
  200 characters. The 0.5.2 entry said a start refuses a CRL whose named key "did not sign it": it
  refuses only where the engine ran the check with that key and it failed, so a signature of
  another kind than the key loads with a WARNING. (vault BACKLOG #3506)
