- **A DATABASE send whose cursor the driver refuses retries.** A driver error from allocating the
  statement's cursor on a borrowed connection used to escape the send unclassified. It is now
  classified as a connect failure, since nothing ran: retried, or a stopped lane on a refused
  login or a missing driver, never a dead-lettered message. A poll, mark, `db_lookup` and
  `DatabaseRef` sync read the same refusal the same way, and each of these sites, the login role
  probe too, now discards that connection rather than lending it again, unless the refusal is a
  configuration or credential fault that a fresh connection would meet too. A lookup still
  fails its message, with an error naming the connect failure. (`BACKLOG #5749`)
