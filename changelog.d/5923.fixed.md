- **The UDP syslog forwarder counts a send that returns an error on this host, and no forwarder
  prints a traceback to stderr.** A `sendto` that returns an error (no route, for example) now
  reads as failing: with a spool the record is kept on disk instead of being lost or deleted as
  sent, and without one it is counted as unsent. A UDP forwarder can therefore now read `degraded`
  and raise the forwarding alerts. With a spool, a UDP collector whose name lookup fails for a
  temporary reason at start is deferred instead of leaving the process without a forwarder.
  Outside the shutdown drain, failed sends on any arm are reported in a throttled ERROR line naming
  the error type, and its number where it has one, with no record content, where the standard
  library printed a traceback and the record to stderr each time. Delivery over UDP is still not
  confirmed; see `[logging]` in [CONFIGURATION.md](../docs/CONFIGURATION.md). (`BACKLOG #5923`)
