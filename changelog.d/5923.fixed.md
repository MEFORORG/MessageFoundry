- **The UDP syslog forwarder counts a send that fails on this host, and no forwarder prints a
  traceback to stderr.** A `sendto` that returns an error (no route, for example) now reads as
  failing and, with a spool, keeps the record on disk instead of deleting it as sent. Failed sends
  on any arm are reported in a throttled ERROR line naming the error type, and its number where it
  has one, with no record content, where the standard library printed a traceback and the record
  to stderr each time. Delivery over UDP is still not confirmed; see `[logging]` in
  [CONFIGURATION.md](../docs/CONFIGURATION.md). (`BACKLOG #5923`)
