- **An `env()` value of `false` now turns off `Ftp(tls=...)` and the `with_*` composers'
  `enabled` flags.** An uncast or `str`-cast `env()` on `with_smart_backend`,
  `with_oauth2_client_credentials` or `with_signing`'s `enabled` handed the connector the text
  `false`, which the SMART and OAuth2 readers took as true. `Ftp(tls=env(...))` chose FTPS whatever
  the value said, `cast=bool` included. Both are now read with the strict boolean spellings, an
  unknown spelling stops the load with the value withheld, and a pin beside a CA that the resolved
  plain-FTP hop would never read is refused. See [CONFIGURATION.md](../docs/CONFIGURATION.md).
