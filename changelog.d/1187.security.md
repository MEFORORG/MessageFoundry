- **The IDE's Live Debug reveals real values for one run, not for the session.** The old *Reveal
  Values* toggle stayed on once clicked, so every later run passed `--show-phi` and showed real
  values in every module until the user turned it off. On a first deployment that toggle would have
  shown message values from runs nobody asked to reveal. Now *Reveal Values for One Run* (or the
  **Values: Hidden** status-bar item) re-runs once with real values shown, and the next run, such as
  the next save, is masked again. *Hide Revealed Values* hides them sooner. The command
  `messagefoundry.toggleRevealValues` is gone. (ASVS 14.2.6, vault `BACKLOG #1187`)
