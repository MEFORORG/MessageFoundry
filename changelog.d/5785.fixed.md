- **A custom role name is checked before it is stored.** `POST` and `PUT /roles/custom` answer
  422 for a blank name, one holding a control character, or one that folds to a built-in role's
  id or label, such as `ADMINISTRATOR`. The fold is case and NFKC with format characters dropped;
  a letter from another script that only looks alike is not caught. A save that re-sends the
  stored name is exempt, so a role stored under a refused name can still have its permissions
  edited. (`BACKLOG #5785`)
