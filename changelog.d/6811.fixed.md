- **The sandbox worker reads a two-component Linux kernel release with a suffixed minor.** A
  release such as `6.12-rc4` or `5.15-aws`, from a custom build rather than a stock kernel, which
  reports three components, used to read as unparseable, so `[sandbox].mem_mb` became an absolute
  `RLIMIT_AS` cap rather than `RLIMIT_DATA` headroom above the loaded graph. A non-Linux kernel, or
  a release with no leading `major.minor`, keeps the `RLIMIT_AS` fallback. (`BACKLOG #6811`)
