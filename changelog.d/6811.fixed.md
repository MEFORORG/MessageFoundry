- **The sandbox worker reads a suffixed Linux kernel minor as its number.** A release such as
  `6.12-rc4` or `5.15-aws` used to read as older than Linux 4.7, so `[sandbox].mem_mb` became an
  absolute `RLIMIT_AS` cap rather than `RLIMIT_DATA` headroom above the loaded graph. A non-Linux
  kernel, or a release with no leading `major.minor`, keeps the `RLIMIT_AS` fallback.
  (`BACKLOG #6811`)
