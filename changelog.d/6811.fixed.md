- **The sandbox worker reads a two-component Linux kernel release with a suffixed minor.** Stock
  kernels report three components, so this affects custom builds. A release such as `6.12-rc4` or
  `5.15-aws` used to read as unparseable. `[sandbox].mem_mb` then became an absolute `RLIMIT_AS`
  cap. It is now `RLIMIT_DATA` headroom above the loaded graph. A non-Linux kernel now always gets
  the `RLIMIT_AS` cap. Before, a non-Linux release numbered 4.7 or higher, such as Darwin
  `23.1.0`, got `RLIMIT_DATA` where `/proc/self/status` gave a `VmData`. A release with no leading
  `major.minor` keeps the `RLIMIT_AS` fallback. (`BACKLOG #6811`)
