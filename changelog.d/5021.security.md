- **A `connection_error` alert no longer sends its reason off the box.** The webhook and email
  notifier bodies carried the outbound failure's `safe_exc` reason, which can echo a partner's
  reply text. They now carry the connection, the kind and the exception class, or the fixed token
  `unnamed error` for a class that is not a plain identifier. The reason is still stored as the
  alert instance's masked, revealable reason. See [PHI.md](../docs/PHI.md) rows 10 and 11.
