- **Every refusal of a route that declares no authorization is now counted.** The engine used to
  log only the first refusal of such a route, so a later burst wrote nothing. Each refusal now
  counts toward that route, and the ERROR line repeats at most once a minute for each route,
  carrying how many refusals came since the previous line. Refusals after a burst's last line reach
  the log only when the route is refused again. The line names the route's path template and never
  the request. (`vault BACKLOG #2846`)
- **The route walk in `scripts/security/route_gates.py` says what the refusal makes of each row.**
  A row's `kind` is `gated`, `public`, `in-body`, `refused` or `outside`, and `declaration` carries
  the reason a `public_route` or `authorizes_in_body` mark gives. The DAST sweep fails a run whose
  ungated routes are not all declared public with a reason. The walk reads a mounted application's
  WebSocket hooks from that application, and a test now tries every non-boolean `create_app`
  parameter for routes the full-surface app lacks. (`vault BACKLOG #2846`)
