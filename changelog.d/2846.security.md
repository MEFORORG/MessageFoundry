- **Every refusal of a route that declares no authorization is now counted and logged.** The
  engine used to log only the first refusal of such a route, so a later burst wrote nothing. Each
  refusal now counts toward that route, and the ERROR line repeats at most once a minute for each
  route, carrying how many refusals it stands for. The line names the route's path template and
  never the request. (`vault BACKLOG #2846`)
