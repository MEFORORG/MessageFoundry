`provision-admin` runs its repair branch's session revokes on a longer retry budget, up to 30 attempts over up to five minutes, since the command has no request deadline; request callers keep the 15-second budget. A revoke it gives up on after the Administrator grant now refuses the command with text naming `messagefoundry admin-revoke-sessions`, the host command that ends the earlier holder's session, and one given up on before the grant refuses it with no password or role written. A run the grant refuses after setting the password also ends the account's sessions.
