- **A credential value masks a later braced password's tail, when that tail is only lower case
  letters and spaces.** A plain value under a `MEFOR_*`, token, session or `api_key` label ran on over
  a later `PWD=` (or other password-word label) whose braced value held a space, and stopped at that
  space, so the shipped log scrub and the support bundle would print the tail, for example
  `MEFOR_STORE_DSN=Server=h;PWD={p w}` gave ` w}`. The value now takes that label and its braced
  value, and writes the tail back with each letter masked, so that line gives ` x}`: the tail's
  spaces, word lengths and closer still print, and so does a word the mask keeps whole for a later
  pass, such as one ending in `mrn` before a space. The tail is an allowlist: after the braces' first
  white space, which must be a plain space, they may hold only lower case ASCII letters and plain
  spaces, with no `bearer`, `basic` or `digest` before a space. Any other character there, at least a
  digit, a capital letter, punctuation, a tab or other white space, and a character outside ASCII,
  leaves the line exactly as it printed before, so `PWD={p w Summer2024}` still prints its tail. An
  all-lower-case spaced tail is the only one hidden beyond what the previous code hid. Before the
  braces' first white space they must not hold a `;`, `,`, `&`, `{`, quote or line break. The `=` or
  `:` must follow the keyword directly, and the `{` the separator, with no white space at either
  place. Anything else prints as before. At least these still print: `PWD= {p w}`, `PWD ={p w}`,
  `%3BPWD={p w}`, a label glued on by `_`, a quote after the label, and a key-material or token label
  with a braced value. On the installed log chain a `token=` line still prints the tail, because the
  query filter runs first. Code review found shapes where an earlier form of the change, which refused
  characters one by one, printed a value the previous code hid in the bundle and on the store path,
  among them `Bearer abcd.PWD={pp 2024-01-01t09:15private_key=vq9}vq10 rest` and
  `token=a;PWD={pp mrn[vq7code=x}`; those now print exactly as before. A random differential and a
  shape grid against the previous code are evidence on a sample, not a proof that no such line is
  left. (`BACKLOG #2966`)
