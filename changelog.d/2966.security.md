- **A credential value no longer prints the tail of a later braced password.** A plain value under a
  `MEFOR_*`, token, session or `api_key` label ran on over a later `PWD=` (or other password-word
  label) whose braced value held a space, and stopped at that space, so the shipped log scrub and
  the support bundle would print the tail, for example `MEFOR_STORE_DSN=Server=h;PWD={p w}` gave
  ` w}`. The value now takes that label and its braced value, and writes the tail back with every
  letter and digit masked. Measured against the previous code on about 1.25 million synthetic
  lines, on the write-time pass, the installed log chain and the support bundle: no value prints
  that the previous code hid. A label glued on by `_`, a quote after the label, and a key-material
  or token label with a braced value still print as before. (`BACKLOG #2966`)
