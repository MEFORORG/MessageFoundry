- **A traced dry run no longer drains a Handler's single-pass iterable of `Send`s.** A Handler
  returning an object whose `__iter__` hands back a stored generator (iterable, but not an
  iterator) was walked by the trace observer before the dry run partitioned it, so the traced run
  reported `FILTERED` with zero deliveries where the untraced run delivered. The observer now walks
  only `list`/`tuple`/`set`/`frozenset`, as the Router half already did, and marks any other
  iterable Handler return `lazy_result` instead of reading it. (`BACKLOG #6823`)
