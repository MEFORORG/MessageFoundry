- **A connection's own keep-forever retention override now writes an `AUDIT:` line under
  `enforcement = warn` too.** With no `[security].allow_keeping_phi_indefinitely`, an inbound
  `messages_days = 0` or an outbound `dead_letter_days = 0` passed the graph with a plain warning, so
  a site on that dial would have kept those bodies forever with no audited record. The registry guard
  now writes a WARNING-level `AUDIT:` line naming each connection, with the remedy, and still passes
  the graph (owner ruling 2026-11-01). The graph still loads with no acknowledgement, and those
  bodies are still kept forever. The global body-window gate still audits only under `enforce`.
