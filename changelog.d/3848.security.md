- **A wrong password at the directory step-up re-bind is counted even when the unbind fails.** A
  re-bind the directory refused with `invalidCredentials` (49), followed by an ldap3 error from the
  connection's unbind, used to read as the directory being unavailable, so it was charged to
  neither the account lockout nor the per-session re-proof cap. An unbind error is now logged at
  debug level and never raised over the bind's answer, and the socket is closed even when the
  unbind's send fails. A bind the directory ended busy or unavailable is still not counted. A
  proved password whose unbind fails now steps up rather than reading as an outage.
  (`BACKLOG #3848`)
