- **A Test Bench collection run writes its case bodies owner-only, and a crashed run's files are
  removed by the next run.** The run's temp directory is mode `0700` and each case file `0600`, created
  exclusively, on POSIX; on Windows the per-user temp directory's ACL governs. A directory a crash left
  behind is deleted by the next collection run once it is over an hour old. The dry-run is handed that
  directory rather than one path per case, so a large collection no longer fails on the length of the
  command line.
