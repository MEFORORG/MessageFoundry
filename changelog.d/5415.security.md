- **A Test Bench collection run writes its case bodies owner-only on POSIX, and a crashed run's files
  are swept later.** The run's temp directory is mode `0700` and each case file `0600`, created
  exclusively; on Windows those modes do nothing and the temp directory's own ACL governs. A
  directory a crash left behind is deleted when the Test Bench next opens or runs a collection, once
  it is over an hour old, and on POSIX only when this user owns it; until then it stays on disk. The
  dry-run is handed that directory rather than one path per case, so a large collection no longer
  fails on the length of the command line.
