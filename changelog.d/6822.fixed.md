`messagefoundry dryrun --trace --show-phi` now writes valid JSON when a traced local holds a NaN or
Infinity float, which it renders as the string `"nan"`, `"inf"` or `"-inf"`, or an int longer than
120 characters, which it renders as `"<int: too large>"`. Before, the trace carried the bare tokens
`NaN`/`Infinity`, which JSON does not allow, and an int past the interpreter's 4300-digit conversion
limit made the command fail with a `ValueError`.
