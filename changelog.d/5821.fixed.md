- **`copy_field` and `split_field` no longer escape a whole field's escapes a second time.** A
  whole-field source copied or split into a component or subcomponent destination is now decoded
  first, as a component source is, so a field sent as `O\S\Brien` reads back as `O^Brien` there.
  A whole-field destination still takes the raw text as it is. (`BACKLOG #5821`)
