- **A layered search refuses a blanked preset rather than widening, and no longer answers 500 on a
  cipher error reading a preset.** `GET /search/layered` read a preset whose stored criteria were
  NULL or empty as an empty filter, so a narrowing preset blanked outside the store dropped out and
  the search matched rows it would have excluded. It now answers **423** and logs a WARNING. A
  cipher error on the preset's criteria that is not a failed tag, for example an unmarked value in
  a keyed store or a value Vault Transit refused, answers **423** where it answered 500, logged
  at ERROR with the error's type name alone, and a
  Transit outage answers **503** with `Retry-After`, as the upload routes do since `BACKLOG #3734`,
  logged at WARNING where the 500 logged at ERROR, as the upload routes log an outage.
  A cipher error on a message row the search then scans is not covered by this change. A layered
  search that returns rows now also feeds the coalesced `summary_access` audit, as
  `/messages/search` does. (`BACKLOG #5523`)
