- **The dialling CA check of a lane reads the CA once per check, and a repeat of its last pass
  writes no audit rows.** It read the file, its ACL and its path twice, so on Windows each check
  ran `icacls` twice, and what it remembered could come from another read than the one it judged.
  Under `warn`, a CA that passed with an exposed or unjudged ACL or path wrote its violation rows
  at every check, as a scheduled poller retries at every window tick. A pass is now remembered
  once its rows are written, and only the same setting with the same bytes, ACL, pin and path
  findings is passed from memory. A reload that removes or renames a lane now drops that lane's
  refusal mark and the check's memory of it. (`BACKLOG #3188`)
