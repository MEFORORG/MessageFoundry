- **On Python 3.15 the apiclient and the tray probe stop offering SHA-224 TLS signature schemes
  too.** Their verifying contexts, on both trust branches, now drop `rsa_pkcs1_sha224`,
  `ecdsa_sha224` and `dsa_sha224` the way every engine-built context does. The narrowing moved into
  the stdlib-only `messagefoundry.tls_sigalgs`, which `tls_policy`, the apiclient and the tray all
  call, so there is one copy and none to drift. ADR 0113 adds that module to the tray-importable
  list. The startup TLS-floor probe is left as it is, on purpose: it verifies no certificate, and
  its legacy offers carry no signature-scheme list. Python 3.14 is unchanged.
  (`BACKLOG #3414`, ASVS 11.4.1)
