- **The docs now warn against pinning SQL Server's own self-signed certificate.** With no
  certificate installed, SQL Server generates a self-signed one during startup. A
  `[store].ssl_root_cert` pin of it stops matching after a service restart, and every store
  connection is refused. The warning is in the `ssl_root_cert` row of
  [CONFIGURATION.md](../docs/CONFIGURATION.md) and in
  [DEPLOY-SERVER-DB.md](../docs/DEPLOY-SERVER-DB.md) section 5.1. (vault `BACKLOG #3714`)
