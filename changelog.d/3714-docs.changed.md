- **The docs now warn against pinning SQL Server's own self-signed certificate.** When SQL
  Server has no certificate it can use, it generates a self-signed one during startup. A
  `[store].ssl_root_cert` pin of it would stop matching after a service restart, and every
  store connection would be refused. The warning is in the `ssl_root_cert` row of
  [CONFIGURATION.md](../docs/CONFIGURATION.md) and in
  [DEPLOY-SERVER-DB.md](../docs/DEPLOY-SERVER-DB.md) section 5.1. (vault `BACKLOG #3714`)
