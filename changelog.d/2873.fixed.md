- **`extract_obx_document`, `embed_obx_document` and `strip_documents_in_hl7` refuse a message
  whose delimiters cannot be read as `BinaryCarriageError`.** At least on an `MSH-2` shorter than
  four encoding characters, a body with no `MSH`, or an `MSH-1` a Handler set to anything but one
  character, each used to let out a bare `ValueError` that quoted `MSH-1` and `MSH-2`; each now
  raises the module's documented error, naming the cause without quoting either field.
  `embed_obx_document` refuses before it sets anything, and `strip_documents_in_hl7` refuses only
  a message that has an OBX. A body with a short `MSH-2` is still accepted at the listener's
  parse; a body with no `MSH` is still refused there. (`BACKLOG #2873`)
