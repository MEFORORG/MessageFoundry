- **A federated step-up flow names the user who started it.** The flow staged by
  `begin_oidc_step_up` now carries that session's user id, and `AuthService.oidc_step_up_actor`
  returns it without consuming the flow, replacing `oidc_flow_is_step_up`. The console's OIDC
  callback uses it to charge an IdP step-up's return to that user's per-actor re-authentication
  budget rather than the shared sign-in budget, so a sign-in flood could no longer refuse a
  federated step-up on a deploying site. (`BACKLOG #3374`)
