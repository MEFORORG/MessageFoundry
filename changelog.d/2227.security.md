- **Turning a credential reminder off is now named as a security loosening.**
  `[cert_monitor].warn_days = 0` and `[secret_rotation].warn_days = 0` each turned a reminder off
  with only a debug line. Each is now listed, as `cert_monitor.warn_days` and
  `secret_rotation.warn_days`, in the serve-time warning, `messagefoundry security show` and
  `GET /security/posture`. The `[alerts]` recipient gate also counts the secret-rotation reminder
  now. Before, a config with the other two reminders off passed the gate with no recipient while
  that reminder still ran. `security_loosenings()` takes a new required `cert_monitor` argument.
  (`BACKLOG #2227`)
