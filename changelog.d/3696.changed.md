- **A paged LDAP group search has one overall deadline, and its cap counts groups, not pages.**
  All the pages of the nested group search now share one deadline, the new
  `[auth].ad_group_search_deadline`, 120 s by default. Each page's reads stay bounded by
  `[auth].ad_receive_timeout`. Before, each page could take the whole receive timeout. A search
  still paging at the deadline is refused as the directory not answering. The search is now
  refused past 10,000 groups at any page size. Before, it was refused past 20 pages, which is
  2,000 groups at 100 a page. Both refusals warn. **The session reconciler pages for an account
  either refusal leaves unrevoked**, as `ad_reconcile_aborted`, once as the account enters that
  state rather than on every pass; a plain directory outage still pages nobody. A deadline above
  its default is a named loosening. The limits are in [CONNECTIONS.md](../docs/CONNECTIONS.md),
  the Active Directory rows of Table B. (vault `BACKLOG #3696` items 3 and 4)
