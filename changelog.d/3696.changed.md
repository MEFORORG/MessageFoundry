- **A paged LDAP group search has one overall deadline, and its cap counts groups, not pages.**
  All the pages of the nested group search now share one `[auth].ad_receive_timeout`: each page's
  reads wait at most what is left of it, and a search still paging when it is spent is refused as
  the directory not answering, where before every page could take the whole timeout. The search
  is refused past 10,000 groups whatever page size the directory returns, with a WARNING, where
  before it was refused past 20 pages, which a directory capping a page at 100 reached at 2,000
  groups. See [CONFIGURATION.md](../docs/CONFIGURATION.md). (vault `BACKLOG #3696` items 3 and 4)
