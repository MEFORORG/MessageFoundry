- **A paged LDAP group search has one overall deadline, and its cap counts groups, not pages.**
  All the pages of the nested group search now share one `[auth].ad_receive_timeout`. Before,
  each page could take the whole timeout. A search still paging at the deadline is refused as
  the directory not answering. The search is now refused past 10,000 groups at any page size.
  Before, it was refused past 20 pages, which is 2,000 groups at 100 a page. Both refusals warn.
  The deadline's limits are in [CONNECTIONS.md](../docs/CONNECTIONS.md), the Active Directory
  row of Table B. (vault `BACKLOG #3696` items 3 and 4)
