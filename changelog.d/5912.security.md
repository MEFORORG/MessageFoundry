- **A SOAP fault's class is read only from its code element.** The code is now the Fault's first
  child, a comment, CDATA section or processing instruction before it stepped over whole: SOAP
  1.1's `faultcode`, or SOAP 1.2's `Code` and the `Value` that is the Code's own first child. The
  shipped code took the Fault's first `Value` ahead of any `faultcode`, so a `Value` in a Role,
  Node, Reason or Detail that came before the Code's own Value, or one ahead of a SOAP 1.1
  `faultcode`, decided the class instead; on a first deployment that could have made a Sender
  fault read as a Receiver one and retry until the attempt limit. A Fault whose first child is
  neither, including a SOAP 1.1 Fault whose `faultcode` is not first, now reads as a permanent
  fault, as one with no code always did; it is never read as delivered. Where a Fault is found,
  and whether one counts, is unchanged. (`BACKLOG #5912`)
