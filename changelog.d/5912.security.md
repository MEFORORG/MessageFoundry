- **A SOAP fault's class is read only from its code element.** The code is now the Fault's first
  child: SOAP 1.1's `faultcode`, or SOAP 1.2's `Code` and the first `Value` inside it. A `Value`
  anywhere else in the Fault, in a Reason, Node, Role or Detail, or one ahead of a `faultcode`,
  used to decide the class, so on a first deployment it could have made a Sender fault read as a
  Receiver one and retry until the attempt limit. A Fault whose first child is neither now reads as
  a permanent fault, as one with no code always did; it is never read as delivered. Where a Fault
  is found, and whether one counts, is unchanged. (`BACKLOG #5912`)
