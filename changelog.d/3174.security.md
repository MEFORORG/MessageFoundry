- **Federated step-up and binding follow-ups.** These gaps from the IdP step-up work are
  closed. (vault BACKLOG #3174)
  - The engine refuses to mint an `oidc` session with no IdP `auth_time` at the one place every
    session is minted, not only in the directory sign-in path. Such a session could never step up.
  - An IdP step-up refuses a directory answer whose object id is not the account's own, as
    `directory_identity_conflict` or `directory_object_id_missing`, before it trusts the answer's
    groups.
  - A federated bind refused because another account holds the identity, or because the account
    is local, now writes an `auth.federated_bind_refused` row. A changed-pair refusal row now
    records the pair the account held, wherever the refusal read it.
  - The order of the IdP-clock test and the directory lookup is pinned by a test, and the
    `sessions.idp_auth_time` migration is tested on Postgres and SQL Server.
