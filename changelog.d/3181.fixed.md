- **`rotate-key` fails, and records no key rotation, when it skips an uploaded file.** It used to
  print `OK`, exit 0 and write the ASVS 13.3.4 rotation stamp even when an uploaded file was left
  partly under the prior key, so an operator or a wrapper could retire a key that was still needed.
  It now prints `PARTIAL`, exits 1 and writes no stamp; the run that completes writes it. One upload
  that no configured key opens no longer aborts the whole pass: it is left as it was and counted as
  a skip, and every other upload is re-sealed. An upload whose body is missing or is not text, under
  a sealed sidecar, is no longer counted as a skip, since no re-run can change it; `rotate-key`
  re-seals its sidecar and prints a note instead. (`BACKLOG #3181`)
