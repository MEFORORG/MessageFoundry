- **A reload that runs while a log-write halt waits for the reload lock can no longer rebind a
  listener over the internal stages the halt shuts down.** The halt sets its latch at once but
  marks the inbounds it halts only once it holds the reload lock, and the reload's rebind gate
  refused only an inbound already marked. A reload holding the lock had unbound every listener and
  was rebinding them, so it would have rebound each one, and the halt, which read its bound list
  before the lock, would have left them bound and ACKing into halted lanes. The gate now refuses
  any inbound while the latch is set and the log is still unwritable, and halts it, so an inbound a
  reload adds after a halt is refused too. A halt that waited behind a stop, a start or a newer
  halt now stands down rather than pausing lanes into a run it no longer belongs to, and one whose
  latch a recovery probe cleared while it waited stops nothing. It still sends its one page.
  (`BACKLOG #5704`)
