- **The self-signed certificate the engine generates for a loopback bind names 127.0.0.1, ::1
  and localhost.** A pair the engine mints or renews for a `127.0.0.1`, `::1` or `localhost`
  bind now names all three, so a client on the engine's machine verifies it at whichever of the
  three it dials, where the engine listens at that address. A wildcard bind still names only
  itself and its own family's loopback, and any other bind names itself alone. The pair never
  adds the machine's host name beyond the bind host. (`BACKLOG #5790`)
