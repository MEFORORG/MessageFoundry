- **Every documented `gh attestation verify` command now pins the release workflow and the tag.**
  The install guides and the CI gate `messagefoundry init` writes passed `--repo` alone, which
  accepts an attestation from any workflow or ref in the repository. They now add
  `--signer-workflow` and `--source-ref`. The scaffolded gate derives the tag from the pinned wheel,
  so a pre-release wheel `0.5.0rc1` checks against tag `v0.5.0-rc1`. A config repo scaffolded
  before this change keeps the old gate until its `check.yml` is updated by hand. (`BACKLOG #2534`)
