- **A CRL whose issuer name differs only in ASCII letter case now counts as the same issuer.**
  OpenSSL folds the case of the letters A to Z when it compares names, so it takes
  `CN=PARTNER CA` and `CN=Partner CA` for one issuer. The engine grouped CRLs by the exact issuer
  text. So a running-hop reload refused such a replacement with a restart, and said it superseded
  nothing. A start refused a future CRL beside a current one in other case as not in effect, and
  so did the expiry monitor's check of a CA file. All three now group by the issuer name as the
  signature check compares it, with ASCII case folded. A case change outside ASCII, or any other
  change to the name, still counts as another issuer. (`BACKLOG #3755`)
