- **A traced dry-run no longer keeps Message writes it will never emit.** Once an invocation hit
  the 5,000-event cap, `dryrun --trace` stopped emitting lines but went on holding every later
  `msg[...]` write in memory, so a long mutating loop grew without bound. A write past that cap is
  now dropped, under the invocation's existing `truncated` flag. A separate per-invocation cap of
  5,000 writes bounds the writes a Handler's helper makes on a single traced line; a write past it
  is dropped and the invocation carries a new `writes_truncated` flag. A write that
  `Message` refuses is no longer recorded. (`BACKLOG #6824`)
