- **`cert self-signed` writes both files or neither, and refuses an existing `cert.pem`.** It
  replaced a `cert.pem` with no `key.pem` beside it without a word, and a failed certificate write
  left the new key behind, so every later run refused. It now refuses an existing `cert.pem` as it
  does an existing `key.pem`, and removes the key it wrote when the certificate write fails. A
  common name over 64 characters or not in ASCII, or a `--days` past the year 9999, is now the
  command's own failure (exit 2, and `{"error": ...}` under `--json`) rather than an uncaught
  exception. The console output labels an IP address SAN as `IP:` rather than `SAN(DNS)`, and
  `cert self-signed` and `cert import` state the key's protection as this platform applies it.
  (`BACKLOG #3073`)
