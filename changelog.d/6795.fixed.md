- **A SQL Server stepdown no longer reports a drain it did not make.** The lease release counted
  `cursor.rowcount`, which a session-wide `SET NOCOUNT ON` turns into `-1` even when the
  owner-scoped `UPDATE` matched nothing, and `-1` reads as released. The release now counts the
  rows its `OUTPUT` clause returns, as other SQL Server writes that must know what they changed
  already do. (`BACKLOG #6795`)
