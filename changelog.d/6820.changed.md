- **`messagefoundry check` reads each reference file once per run.** `check` previews every
  fixture on every inbound, and each preview re-read and re-parsed every file-backed reference
  set. It now builds the reference view once per run and passes it to every preview, through a
  new `reference_view` keyword on `dry_run` and `route_message`. Every fixture reads the same
  snapshot, as every message reads the live engine's cache. A caller that passes no view keeps
  the old behaviour. (`BACKLOG #6820`)
