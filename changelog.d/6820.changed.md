- **`messagefoundry check` reads each reference file once per run.** `check` previews every
  fixture on every inbound, and each preview re-read and re-parsed every file-backed reference
  set. It now builds the reference view once per run, with the new public
  `dry_run_reference_view`, and passes it to every preview through a new `reference_view`
  keyword on `dry_run` and `route_message`. Every read of a value decodes its own copy, as a read
  of the live engine's reference cache does, so a Handler that edits one in a fixture does not
  change what a later fixture reads. A caller that passes no view keeps the old behaviour. The
  `dryrun` command and the traced dry run still read the files for every message.
  (`BACKLOG #6820`)
