- **An LDAP referral pages the directory reconciler without stopping revocation, and one account
  whose probe raises no longer ends the pass.** In the shipped code a referral read as a directory
  outage, so a user search base in another domain of the forest would stop revocation for every
  account and page nobody. A referred account is now left unjudged, every other account in the
  pass is still judged, and every pass with a referral audits `auth.ad_reconcile_referred` and
  raises `ad_reconcile_aborted` with reason `directory_referral` under its own source,
  `directory-reconciler-referral`. A pass of referrals only judges nothing and still pages. Before
  this, one account whose directory probe raised something other than an LDAP error ended the
  whole pass, so it stopped revocation for every account, and step-up returned an error rather
  than an audited refusal. That account is now skipped and the rest of the pass runs; step-up
  refuses it. (`BACKLOG #2241`, `BACKLOG #2538`)
