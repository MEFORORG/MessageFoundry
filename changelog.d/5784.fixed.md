- **An account name an administrator sends is checked before it is stored.** A blank display
  name, one of white space alone, or one holding a control character (NUL included) is refused
  with a 422 on `POST /users` and `PATCH /users/{user_id}`, and the console's user save shows the
  refusal; such a `username` is refused with a 422 on `POST /users/directory` too. An edit that
  re-sends the name already stored is exempt, so a name another writer stored does not block a
  save of another field, and a repair to a clean name is accepted. (`BACKLOG #5784`)
