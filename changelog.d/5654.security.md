- **The anonymizer's leak-check and site-code scrub read escaped and IPv6 values.** In both the
  toolkit and the tee: the MRN-typed check reads an `MR` or `MRN` id type in any subcomponent,
  padded or not; a routable IPv6 address is refused, while at least the loopback, link-local,
  unique-local and documentation ranges pass (PHI.md lists them all); the site-code check and
  scrub find a site code joined to an escaped delimiter or written with a hex escape, and the
  scrub replaces it, escapes and all, with digits of the same width; and the check for a shape cut
  across fields reads each field decoded too. See
  [PHI.md](../docs/PHI.md), *What the leak-check refuses, and what it lets through*.
