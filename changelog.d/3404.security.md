- **The `/ws/stats` live feed would now record why its per-frame re-check stopped it.** The feed
  asks again about the caller's standing before every frame and closes with 1008 on a refusal. That
  close used to write no audit row, so a feed ended by an unmet second factor or a missing
  notification address left no trail. It now writes one `ws_stats.stopped` row per stopped feed,
  with the frames sent and a reason such as `mfa_unmet`, `notify_email_due` or `session_ended`, and
  never the token. A sign-out or a step-up with the dashboard open usually records `session_ended`.
