- **An AD group map key with an invisible character at either end is refused.**
  `PUT /ad-group-map`, `PUT /ad-group-scope-map` and the web console's AD group page now trim
  only a space, a tab and a line break from a key. A key that still starts or ends with a
  character that does not print, such as a no-break space, an em space, a zero-width space or a
  byte-order mark, gets a 400 with its own reason. Before, the white-space ones were trimmed as if
  they were plain spaces, and a trailing zero-width space was kept and stored a key that matched
  no group. Each refused key that holds such a character is named in its `ascii()` form, so the
  character shows in the message. The DN parser likewise takes only a space, a tab and a line
  break as padding around an attribute type, so a DN pasted wrapped at its commas still maps. A
  character that does not print inside a value, away from both ends, is still part of that value.
  (vault `BACKLOG #3222`)
