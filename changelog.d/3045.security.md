- **A C0 control in an off-box audit record field no longer hides the text beside it, in the
  cases measured.** `json.dumps` escapes the 32 C0 controls before the log filters run, so on a
  first deployment a name, a credential or a date beside one, as in a typed sign-in name, would
  have reached the tee line unredacted. Each text field holding a C0 control is now scrubbed
  before it is encoded, and can ship as `[redacted]`. On each sink, the off-box forwarder
  included, read as the modelled pass of its installed filter chain, the line shows no
  word, a run of letters or digits, that the sink's line hid before this change, and parses
  as JSON wherever that line did; punctuation it hid can show. A client
  can switch the scrub off for its own record by typing a segment-shaped token such as `ABC|`,
  and that record then ships as it did before. The `emit_audit_tee` docstring says what is left.
