- **A refused Kerberos token is audited as a refused sign-in, and the row no longer quotes the
  token.** A token the SPNEGO acceptor refused became a directory error that stored the
  exception's message as `auth.login_error`. That message can carry text parsed from the
  caller's token, such as an unknown mechanism OID. It is now an `auth.login_failed` row with the
  reason `token_refused` and only the error's type. `POST /auth/negotiate` also now audits a token
  that is not base64 as `malformed_token`, the row `GET /ui/sso` already wrote. (`BACKLOG #3196`)
