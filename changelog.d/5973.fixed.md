- **The tray reads an engine on a wildcard bind, or on a bind set in its settings TOML, as up.** A
  `0.0.0.0` or `::` bind is now dialled on the loopback of its family, and the self-signed
  certificate the engine mints for a wildcard bind also names that loopback, so the pinned probe
  verifies it. An operator certificate on a wildcard bind must name that loopback too, or the tray
  needs `engine_url` set to a name the certificate carries. The tray also takes the bind from
  `[security].listen_address` and `[api].port` in the engine's settings TOML when `serve` has no
  `--host`/`--port`. Before, it would have dialled an address nothing can connect to, or the
  default `127.0.0.1:8765`, and shown a running engine as down. (`BACKLOG #5973`)
