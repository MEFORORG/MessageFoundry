- **The tray reads an engine on a wildcard bind as up.** The self-signed certificate the engine
  mints for a `0.0.0.0` or `::` bind also names the loopback of its family, the address the tray
  dials for that bind, so the pinned probe verifies it. An operator certificate on a wildcard bind
  must name that loopback too, or the tray needs `engine_url` set to a name the certificate
  carries. (`BACKLOG #5973`)
