- **Security notices no longer let a username write its own lines, and an administrator's act
  no longer ends with "If this was you".** The temporary-password reminders and the
  enrolment-code notice now print a username that holds a line break as a placeholder, as the
  other notices already did. The notices for an administrator's role change, account disable
  and MFA reset now close with "If you did not expect this change, contact your MessageFoundry
  administrator". A true or false value in a count or deadline field is no longer printed as a
  number or a 1970 date.
