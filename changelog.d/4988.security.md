- **A backup's early sweep of its DR staging root goes by the owner a directory there gets.** It
  went by the process's own owner. On a share whose server sets the owner, a directory carrying the
  process's owner may have been made by another principal, such as SYSTEM on the file server, and
  the sweep would have removed it. The backup now learns the owner from a bare probe directory in
  the staging root, which it removes again, and sweeps by that owner only. When that probe answers
  nothing, the early sweep is off for that run rather than falling back to the process's owner.
  What this leaves open is listed in [`docs/PHI.md`](../docs/PHI.md), section 2's staging row.
