- **A directory change that removes the last enabled Administrator now raises an alert.** A
  directory sign-in's role sync and the session reconciler can take Administrator from an account,
  and neither goes through the console's last-administrator guard. By owner ruling 2026-10-13 the
  directory stays authoritative, so the change still applies. When it leaves no enabled
  Administrator, the engine now raises the `no_enabled_administrator` alert, keyed
  `user:<username>` with `via` set to `ad-sync` or `ad-reconcile`, and writes one
  `auth.no_enabled_administrator` audit row. With none left, `provision-admin` runs again at the
  host. (`vault BACKLOG #3229`)
