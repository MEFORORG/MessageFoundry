- **An `env()` on a `deployed=False` connection no longer fails the ADR 0050 AC-3 value-file
  check.** Under an explicit project root with no `<env>.toml`, `serve` and the offline commands
  that run the check (at least `validate`, `graph`, `dryrun` and `check`, given `--project-root`
  and `--env`) exited 2
  because of a connection that is switched off and never resolves its values. The check now
  counts the `env()` references of deployed connections, lookups and reference sets. So that
  turning such a connection on cannot slip past it, a managed engine given an explicit
  `[environments].base_dir` now runs the same check as a registry preflight at its first load,
  every real reload and a DR activation, and refuses a reload whose graph references `env()` when
  the value file is absent. A dry-run reload does not run it. (`BACKLOG #5775`)
