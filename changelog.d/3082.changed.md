- **A directory refusal at the second factor or a step-up names a new sign-in as well as a later
  try.** When the directory cannot confirm a directory account at `/auth/mfa-verify` or
  `/me/reauth`, the 403 now says to try again later and, if it is still refused, to sign out and
  sign in again, or to ask an administrator. It used to name only a later try and an administrator.
  One text covers every cause and names no group or role. [SECURITY.md](../docs/SECURITY.md) says
  which fix clears which cause. (`BACKLOG #3082`)
