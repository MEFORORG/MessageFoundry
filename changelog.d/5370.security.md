- **Strict X12 validation keeps more interchange text out of tracebacks and logs.** A refusal no
  longer chains the pyx12 exception, whose message can quote a whole ISA, so a traceback would have
  carried ISA02 and ISA04 on a deploying site. `X12ValidationError` now names only the exception's
  class. `X12ValidationResult`'s repr leaves out `ack`, which echoes sender values.
  `X12SegmentError.segment_id` is `None` unless the value is shaped like an X12 segment id, so a
  wrongly delimited segment no longer lands in `segment_id` or `message`. A two- or three-character
  sender value of that shape is still kept. (`BACKLOG #5370`)
