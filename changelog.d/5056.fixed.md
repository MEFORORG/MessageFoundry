- **A store archive whose row-count compare reads nothing now fails verify.** The compare is keyed
  off the manifest's own tables, so a manifest with empty or missing `row_counts` had no key to
  mismatch, and `restore-verify`, the verify after a backup and `restore` passed it on counts nobody
  compared. A store snapshot whose schema holds no table did the same against an all-zero manifest.
  Both are now a FAIL, and `restore` refuses before it places anything, with a reason that says the
  compare read nothing. A full archive's manifest always lists its store's tables, and a config-only
  archive returns before the compare, so neither is affected. (`BACKLOG #5056`)
