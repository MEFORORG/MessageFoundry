- **A gated JSON route refuses a caller with no session before it reads the request body.**
  FastAPI decodes a declared body before it runs a route's dependencies, and the sign-in check
  is a dependency. So 34 gated routes answered a malformed body from the parser, with a 422 or
  a 400, where every other unauthenticated request gets the gate's 401. One route class now
  runs the gate's authentication step first on every gated route, so the answer no longer says
  whether the body parsed or whether the route takes one. A signed-in caller gets what it got
  before. One request still pays one session lookup. A signed-in caller whose body does not
  parse now pays that lookup too. [SECURITY.md](../docs/SECURITY.md) has the detail under
  *Enforcement model*. (`vault BACKLOG #2739`)
