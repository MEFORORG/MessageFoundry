- **Uploaded logs also refuse four ZIP record signatures anywhere in the body, as defence in
  depth.** The four are `PK\x03\x04` (local file header), `PK\x01\x02` (central directory header),
  `PK\x05\x06` (end of central directory) and `PK\x07\x08` (data descriptor); other ZIP record
  signatures are not scanned. An appended ZIP or DOCX was already refused: every archive a ZIP
  reader extracts carries NUL bytes, and the whole-body NUL check (`BACKLOG #5551`) answers it 415.
  The new check also refuses a NUL-free byte run carrying one of the four. (`BACKLOG #5368`)
