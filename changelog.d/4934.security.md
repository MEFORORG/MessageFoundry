- **`rotate-key` now opens its rotation record, when it opens one, from a new `open_store` hook,
  `before_first_write`, which a writable open runs before its first write under the store key.** A
  read-only open does not run it. See the `open_rotation_record` docstring.
  **`serve` can now refuse to start on a changed store key the keyed audit chain cannot follow.**
  `docs/SECURITY-LOOSENING.md` names stores the refusal does not cover.
  `[secret_rotation].allow_lost_audit_range_key = true` starts anyway, for a key that is truly
  lost; it logs the refusal as a WARNING, the chain breaks at that start's first audit row, and it
  is reported as a security loosening. The `admin-*` commands do not refuse.
  (`BACKLOG #4934`, `BACKLOG #4936`)
