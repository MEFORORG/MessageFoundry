- **`messagefoundry security set` refuses a null reset of a key `[security]` does not define, and
  says when an edit changed nothing.** A reset of a misspelled key would have exited 0 and reported
  the key as set, leaving the loosening the operator meant to reset in place. It now exits non-zero,
  names the key and its nearest spelling, and writes nothing; a key the file does carry can still be
  removed. The JSON result's `keys` lists only the keys written or removed, a new `unchanged` list
  names the resets that found nothing and the values the file already held, and `op` is
  `unchanged` when nothing changed. (`BACKLOG #5327`)
