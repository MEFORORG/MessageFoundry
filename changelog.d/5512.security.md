- **An empty host no longer counts as loopback on the cleartext, revocation and trust-anchor
  checks.** The shared on-box check read `""` as this machine, so in the shipped code a hop with an
  unset host would have skipped those checks while its real destination was unknown. Each caller
  now says what an empty host means. A blank HTTP listener host binds `127.0.0.1` and stays on-box,
  a log forwarder with no host has no hop to judge, and the log-forwarding and key-share checks
  still count a blank value as this host. A PostgreSQL store with a blank `server` and a generic
  ODBC `server` of spaces are judged off-box, so each is refused under
  `[security].enforcement = enforce` unless the hop is otherwise covered. (`BACKLOG #5512`)
