- **The undeclared-proxy warning names both ways to declare a proxy.** `serve` prints it when
  `[security].web_console_public_address` is set, no proxy is named and `[security].require_mfa` is
  off. It told the operator to declare the proxy with `[api].tls_terminated_upstream` and
  `trusted_proxies`. It now says to name the proxy in `[api].trusted_proxies`, with a declared
  terminator if the proxy terminates TLS or an operator `[api].tls_cert_file` if it re-encrypts to
  the engine. Either one makes the instance count as exposed. The message that refuses
  `[api].trusted_proxies` without one of those two says so as well. (vault `BACKLOG #3102`)
