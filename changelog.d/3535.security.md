- **A config snapshot treats a Windows share it cannot reach as a fault, not an absent path.**
  Windows errors 53 and 67 reach Python as a `FileNotFoundError`, so a config directory, a
  `codesets/` or `environments/` folder, or a module on such a share read as absent. A digest that
  gates a dual-control release would then have gone on without those files. A strict read now
  raises, and an ordinary read names the path in `unreadable_files`. A start or reload refuses when
  that path is one the load reads, a `codesets/` folder included. A folder or file on such a share
  refuses a release as `digest_unavailable`, and a reload whose target directory is on one answers
  422 `unreadable` where it answered 404 `not_found`. At least a load that finds the directory gone
  at its own first check, `validate_config`, and a value file read from disk still report such a
  path as absent. (vault `BACKLOG #3535`)
