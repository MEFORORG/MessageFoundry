- **A crafted SPNEGO token is now an audited Kerberos refusal, not a 500.** On a host without SSPI,
  pyspnego's Negotiate wrapper raises `StopIteration` or `KeyError` when the first token is a
  `NegTokenResp`. `kerberos_principal` did not catch either one, so `POST /auth/negotiate` and
  `GET /ui/sso` would have answered with a 500 and written no audit row. Both errors are now caught
  with the token errors already caught there. (`BACKLOG #3186`)
