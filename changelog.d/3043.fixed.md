- **A permanent refusal that dead-letters now writes a WARNING.** The delivery worker used to
  dead-letter a permanently refused message, on the single-row and the batch path, with no log
  line at all, so a site watching the engine log would have seen nothing. It now writes one
  WARNING naming the connection, the outbox row, the message id, the exception class and the
  refusal code. The line carries no character of the message and not the refusal's text, which
  stays in the secured store. It is throttled per connection and refusal code: the first
  refusal always logs, later ones within 60 seconds are counted, and the next line reports how
  many went unlogged. The dead-letter itself, its event and its counts are unchanged.
  (`BACKLOG #3043`)
