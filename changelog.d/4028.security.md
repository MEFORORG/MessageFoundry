- **A Vault client names an environment proxy where it uses it.** The first time a Vault or OpenBao
  client sends by way of a proxy from the environment or the system settings, it logs one WARNING
  naming that proxy, never a credential. So `check-privileges`, `verify` and any other command that
  reaches Vault disclose it, and so does a proxy set after start. Before, only `serve` and
  `supervise` named one, once, at start. See
  [CONFIGURATION.md](../docs/CONFIGURATION.md#serve-names-an-environment-proxy-at-start).
  (`BACKLOG #4028`)
