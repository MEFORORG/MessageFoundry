- **A directory revocation that never read the disabled bit no longer tells the holder an
  administrator disabled the account.** The directory session reconciler sent the
  `account_disabled` notice for every whole-account revocation. Only `directory_disabled` reads the
  disabled bit. `directory_absent` (the directory did not find the account) and
  `directory_undetermined` (its `userAccountControl` could not be read) now send a new
  `directory_sessions_ended` notice. It says a directory check ended the account's sessions and to
  contact an administrator if that was unexpected. `directory_disabled` still sends
  `account_disabled`, and a role change still sends `roles_changed`. (`vault BACKLOG #2140`)
