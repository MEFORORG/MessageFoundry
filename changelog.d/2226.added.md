- **`messagefoundry admin-reset-totp` replaces an Administrator's authenticator seed from the
  host.** A sole Administrator whose only factor is TOTP had no way to replace a suspect seed: the
  administrator reset refuses a self-target, and self-service removal refuses the last factor. The
  command runs on the same host gate as `admin-unlock`, with the engine stopped. It shows a new key
  on the console only, and writes nothing until a code from it is typed. One write then swaps the
  seed and the recovery codes with TOTP left on, so the account never has no factor. It ends the
  account's sessions, shows the new recovery codes once, and audits `auth.admin_totp_reset` with the
  OS user as actor. It refuses a non-Administrator, a disabled account and an account with no TOTP.
  See [ADR 0171](../docs/adr/0171-offline-administrator-unlock-a-host-gated-cli-recovery-path-for-a-sole-administrator-lockout.md)
