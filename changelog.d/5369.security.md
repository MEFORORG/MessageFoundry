- **BREAKING: `zip_decompress` refuses more member names, on every platform.** An archive with a
  member name holding a colon (an NTFS alternate data stream on Windows), such as a POSIX
  timestamp name like `2026-11-17T10:30:00.hl7`, or a path component ending in a dot or space
  (which Windows drops), now raises `CompressionError`. So does a component `ntpath.isreserved`
  names: a reserved device name, bare or with any extension, such as `NUL`, `COM1`, `con.hl7` or
  `aux.json`, or a character Windows refuses in a name. That check is a fixed list in the
  standard library, so ordinary names such as `con.hl7` and `aux.json` are refused on every
  platform. A `.hl7v2` member is now checked as HL7 v2 instead of
  accepted unchecked. (`BACKLOG #5369`)
