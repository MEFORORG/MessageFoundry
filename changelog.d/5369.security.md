  every platform, an archive with a member name holding a colon, a path component ending in a dot
  or space, or a component `ntpath.isreserved` names (at least a device stem such as `NUL` or
  `con.hl7`, and the characters Windows refuses in a name) now raises `CompressionError`. A
  `.hl7v2` member is now checked as HL7 v2 instead of accepted unchecked. The DR config restore
  keeps its earlier name check. (`BACKLOG #5369`)
