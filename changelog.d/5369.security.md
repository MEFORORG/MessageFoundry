- **BREAKING: `zip_decompress` and the DR config restore refuse more member names, on every
  platform.** A member name holding a colon (an NTFS alternate data stream on Windows), or a path
  component ending in a dot or space (which Windows drops), is now refused: `zip_decompress` raises
  `CompressionError`, and `restore --config-to` refuses the bundle, so `config/conn.toml:hidden`
  and `config/routers.py.` no longer land as a hidden stream or an aliased file. So is a component
  `ntpath.isreserved` names: a reserved device stem such as `NUL`, `aux.py`, `con.hl7` or `COM1`,
  or a character Windows refuses in a name, so `config/nul` no longer goes to the device. That arm
  is a static list and deliberately over-refuses; which names a Windows build rewrites is recorded
  on `_win_opens_another` in `messagefoundry/pipeline/dr_backup.py`. `archive_member_name_reason`,
  which both call, refuses the same names. A `.hl7v2` member is now checked as HL7 v2 instead of
  accepted unchecked. (`BACKLOG #5369`)
