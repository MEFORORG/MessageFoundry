- **BREAKING: `zip_decompress` refuses more member names, on every platform.** An archive with a
  member name holding a colon (an NTFS alternate data stream on Windows), or a path component
  ending in a dot or space (which Windows drops), now raises `CompressionError`. So does a
  component `ntpath.isreserved` names: a reserved device stem such as `NUL`, `con.hl7` or `COM1`,
  or a character Windows refuses in a name. That arm is a static list and refuses at
  least the names ntpath.isreserved reports; which names a Windows build rewrites is recorded on `_win_opens_another` in
  `messagefoundry/pipeline/dr_backup.py`. A `.hl7v2` member is now checked as HL7 v2 instead of
  accepted unchecked. (`BACKLOG #5369`)
