- **The `Http()` listener answers a body refused at ingress by kind, and names its `ERROR` row.** A
  temporary refusal, the streaming detach's in-flight budget held by other detaches, is answered
  `503` with `Retry-After` instead of `422`, so a sender that treats every `4xx` as final, or the
  engine's own `Rest()` outbound on an engine-to-engine hop, would re-send it rather than give up. A body over a size
  ceiling now answers `413` on every path, the code a body over `max_body_bytes` already got. Every
  other refusal stays `422`, the strict-validation timeout included, even when load rather than the
  body caused it. Each refusal's body now names the `ERROR` row recorded for it as `refused_message_id`, and that
  row's error text names the refusal's kind.
  The DICOM C-STORE SCP maps the same kinds, though no DICOM refusal is temporary today. An HL7 body
  over the size cap is now stored with the reason type `HL7MessageTooLarge` rather than
  `HL7PeekError`. (`BACKLOG #2105`)
