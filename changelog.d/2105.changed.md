- **The `Http()` listener answers a body refused at ingress by kind, and names its `ERROR` row.** A
  temporary refusal, the streaming detach's in-flight budget, is answered `503` with `Retry-After`
  instead of `422`, so a sender that treats every `4xx` as final, or the engine's own `Rest()`
  outbound on an engine-to-engine hop, would re-send it rather than give up. A body over a size
  ceiling now answers `413` on every path, the code a body over `max_body_bytes` already got. Every
  other refusal stays `422`, the strict-validation timeout included. Each refusal's body now carries
  the `message_id` of the `ERROR` row recorded for it. The DICOM C-STORE SCP maps the same kinds: a
  temporary refusal is Out of Resources, and the rest are Cannot Understand. (`BACKLOG #2105`)
