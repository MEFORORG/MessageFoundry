- **`rotate-key` refuses `vault_transit` mode before it touches anything.** Under
  `[store].cipher_provider = "vault_transit"` no run of the command can rotate a value, because the
  store's re-encrypt pass refuses the Transit cipher. The command used to learn that late: it
  resolved a local key, or told the operator to set `MEFOR_STORE_ENCRYPTION_KEY`, which this mode
  never reads; it dialled Vault, opened the store writable, and only then exited 2. It now exits 2
  first, with no key read, no Vault call and no store open, and says to rotate the Transit data key
  in Vault instead. No command moves Transit ciphertext between keys yet. (vault `BACKLOG #2109`)
