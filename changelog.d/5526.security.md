- **A SOAP credential pair is both halves or neither, and the UsernameToken no longer borrows
  HTTP Basic.** `Soap()` refuses at construction `basic_user` without `basic_password`, or the
  reverse, and with `ws_security` on, `ws_username` without `ws_password`, or the reverse. One half
  used to build and send no Basic header, or stamp an empty UsernameToken password. `ws_username`
  and `ws_password` no longer fall back to `basic_user` and `basic_password`, so `ws_security`
  with only the Basic pair now stamps the `Timestamp` alone and sends the password once, as HTTP
  Basic. A configured credential replaces a static `Authorization` header of any spelling. See
  [ADR 0015](../docs/adr/0015-ws-soap-outbound-mtls-wssecurity.md), amendment of 2026-11-10.
  (`BACKLOG #5526`)
