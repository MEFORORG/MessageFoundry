- **An `anon.toml` keep that turns off a default scrub now says so.** A keep records a field as
  reviewed, and it also cancels any default scrub on that field. So keeping `PID-5` to clear a
  `require_full_coverage` refusal would have left the patient name in the dataset on a first use,
  with no notice. `load_rules` now logs a WARNING for each such field, naming the field and the
  kind of scrub it lost, never a value. A keep on a field with no default rule logs nothing.
  `kept_defaults` in `anon/rules.py` returns the same list for a caller that wants to show it.
