- **`[api].trusted_proxies` refuses a CIDR with host bits set, such as `10.0.0.1/24`.** The load
  used to accept one, but uvicorn parses each CIDR strictly and would have treated it as a literal
  that matches no peer, so every client behind that proxy would have shown as the proxy's own
  address. The error names the single address, then the network the entry spans. The env
  form `MEFOR_API_TRUSTED_PROXIES` meets the same check. (`BACKLOG #2488`)
