- **A trust anchor whose PEM block carries an encryption header now refuses.** A `Proc-Type:` or
  `DEK-Info:` line inside a block refuses at start and at reload, before the TLS library sees the
  file. Measured on Windows, loading such a block as `cadata=` did not return within 20 seconds, so
  a start or reload given that file could have hung. A CA certificate is never encrypted.
  (`BACKLOG #2270`)
