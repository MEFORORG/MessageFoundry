- **A trust anchor whose PEM block carries an encryption header now refuses.** A `Proc-Type:` or
  `DEK-Info:` line inside a block of any kind, an encrypted private key included, refuses at start
  and at reload, before the TLS library sees the file. On an encrypted certificate block the
  library could otherwise wait for a password, so a start or reload could hang.
  (`BACKLOG #2270`)
