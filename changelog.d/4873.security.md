- **The SQL Server preset refuses a driver that is not a SQL Server driver, and a `server` holding a
  comma.** The preset sends `SERVER=<server>,<port>` with any `odbc_driver`. psqlODBC passes
  `SERVER` to libpq, which reads a comma as a list of hosts, so on the preset a large `port` could
  name a second host that `[egress].allowed_db` never saw, and the port the check compared bound
  nothing. A `server` holding a comma did the same with any driver. The `odbc_driver` name must now
  name a SQL Server driver or FreeTDS and no PostgreSQL, MySQL or MariaDB driver, `server` must
  hold no comma, and on FreeTDS no `\`. The connection-string build and the egress check both
  refuse, so `messagefoundry check` does too, on all four database factories. Use
  `dialect="generic"` for another driver; see [CONNECTIONS.md](../docs/CONNECTIONS.md).
  (`BACKLOG #4873`)
