- **The SQL Server preset refuses a driver that is not a Microsoft SQL Server driver, and a
  `server` holding a comma or a backslash.** The preset sent `SERVER=<server>,<port>` with any
  `odbc_driver`, so with another driver the port `[egress].allowed_db` compared could bind
  nothing, and a comma in `server` could name a host the check never saw. The `odbc_driver` must
  now be one of Microsoft's registered names, whole and spelled with single spaces, or a path to
  the Microsoft ODBC Driver library. FreeTDS and the bare legacy `SQL Server` are refused. The
  connection-string build refuses, on every factory that builds the preset, and so does the
  egress check where `[egress].allowed_db` has an entry. Why,
  the exact names accepted, and when each refusal runs are in
  [CONNECTIONS.md](../docs/CONNECTIONS.md), *The port an `allowed_db` entry binds*. Use
  `dialect="generic"` for another driver. (`BACKLOG #4873`)
