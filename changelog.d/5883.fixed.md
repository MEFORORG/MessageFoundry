- **A field-path message search and upload browse read past the first value.** A search on a path
  such as `OBX-5` or `PID-3.1` now tests later segment occurrences and field repetitions, so it
  can return more messages than before. A later occurrence holding only delimiters does not count
  as present. Known limit: a stray escape character or a malformed header-like line stops the
  walk, so a search can still under-report such a message. (`BACKLOG #5883`)
