- **Four credential shapes the log scrubbers printed are now hidden or masked.** Each would have
  printed a credential in the write-time log, the support bundle and `GET /logs/tail` on first
  deployment. A connection-string member whose whole key is `key`, `sig`, `signature`, `auth` or
  `jwt` now has its value masked character by character, as `;sslpassword=` does; a key that only
  ends in one of those words, such as `;cache_key=` or `;oauth=`, is not read, and neither is the
  word in prose or a URL query. A member value now runs on over a quote glued right after the
  placeholder an earlier pass wrote (`;PWD=P'Kv9_Sec;` printed `Kv9_Sec`), and over a `;` inside
  a quoted value that closes before a space, `;`, `,`, a closing bracket or the end. A word in a
  member value is kept whole before a `:` or `=` only where a later pass reads it as a label: it
  ends in a kept word that opens at the word's start, after `.`, `_` or `-`, at a camelCase
  capital, or after an escape, or it holds the `MEFOR_` prefix, the bundle marker or a DICOM label
  word, so a password word such as `Passage`, `Statement`, `Barcode`, `Compass` or `Codename` is
  masked. And a label right after a backslash escape written as text, `\n`, `\r`, `\t`, `\b`,
  `\f`, `\xNN` or `\uNNNN`, is read, so `foo\npassword=...` and the `%r` of a multi-line
  configuration no longer print the value. The bundle marker is also kept in a member value in
  either case, since the log chain reads it ignoring case. What still prints, at least: a
  `MEFOR_` label or a bare `Bearer` scheme right after such an escape; a label after an escape on
  a line where reading it would send the camelCase reading back to the reading before it; and the
  shapes the BACKLOG #5030 entry lists. The escape start is a trade, as the `%XX` start was: a
  seeded differential of 60,000 lines against the code before it printed no planted value the
  code before hid on a first pass, and 10 lines printed one on a second pass or a later path,
  where the newly read label hid a separator or a PHI anchor that a later PHI pass needed; it hid
  a value the code before printed on about 4,100 to 5,900 lines per path. (BACKLOG #8429)
