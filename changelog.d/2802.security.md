- **BREAKING: an attachment the sender labelled `text/csv` now downloads as `text/plain` with a
  `.txt` name.** It was served as `text/csv` with a `.csv` name. A sender can start a cell with
  `=`, and a spreadsheet evaluates that cell when it opens the file. The download route cannot
  escape the cell, because the stored document stays verbatim, so it changes the served type and
  name instead. The bytes and the stored label are unchanged, and the message page still shows
  `text/csv`. This covers the double-click only: renaming the file to `.csv`, or importing it into
  a spreadsheet, still evaluates its cells. **Migration:** a client that files downloads by
  `Content-Type` or file name reads the label from the message's attachment list. See
  [CONNECTIONS.md](../docs/CONNECTIONS.md). Seat decision, not an owner ruling.
