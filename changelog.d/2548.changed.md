- **The `[vault]` extra now declares `requests>=2.32.2`.** The Vault clients' send-time hop checks
  run in a requests hook that requests first calls in 2.32.2. The extra used to leave requests to
  hvac, which does not require that version. So an install resolved without the lock could get an
  older requests, on which those checks would not run. The lock already pinned a newer requests, so
  no pinned version moves. ([BACKLOG #2548](../docs/BACKLOG.md))
