- **App-log compression keeps a log that changed while it was being compressed.** The retention
  runner now removes the original only when the path is still the same file (device, inode, size and
  mtime) it read, so lines appended to a log, or a log rotated into the same path, during compression
  are no longer deleted with it. The original and the validated archive are both kept, and the file
  is not counted as compressed. A window of one `stat` then `remove` remains. (`BACKLOG #6805`)
