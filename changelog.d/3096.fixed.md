- **A CA file that is not PEM is now a named refusal, and a DICOM suite refusal names its
  connection.** A `tls_ca_file` or `[tls].internal_ca_file` that reads but holds no usable
  certificate now raises `CaFileUnreadable`, as a missing file already did. It names the setting
  and the connection where the build knows it, and carries no path. Before, it escaped as a raw
  `ssl.SSLError` that named neither. A refused `tls_ciphers` on a DICOM destination now names the
  connection, such as `DICOM destination 'OB_PACS'`. With `tls_ciphers` unset, nothing the
  engine's own narrowing raises can read as "tls_ciphers rejected". (`BACKLOG #3096`,
  `BACKLOG #2977`)
