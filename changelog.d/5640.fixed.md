- **The two-box shardcert drives now check every outbound copy and poll the engine box over
  https.** `shardcert-driver` used to pass a broadcast run that lost most of its outbound copies,
  because its loss check counted distinct messages only. Its verdict now checks each accepted
  message: it must reach as many distinct outbound lanes as the fan-out that SHARDS_READY reports,
  on a kill run too. A surplus or a re-delivery cannot stand in for a lost copy. The total sink
  count against accepted intake times the fan-out is still reported, and is not part of the
  verdict. `shardcert-driver`, `shardcert-drive` and `shardcert-drive-ladder` now poll the engine
  box's API over https by default, signed in as the rig Administrator, and take `--cacert` for the
  engine box's certificate. `shardcert-driver` signs in before it offers any load, and a refusal
  exits 2 with a hint. `shardcert-drive` and each `shardcert-drive-ladder` rung record a refusal as
  a note and run on, because their verdicts never read the poller. `--insecure` keeps the
  plaintext poll, with no credential.
