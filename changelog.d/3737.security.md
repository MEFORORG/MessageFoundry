- **`rotate-key` keeps a rotation record, so a `serve` start no longer stamps a key whose rotation
  did not finish.** The command opens the record in `secret_rotation_meta` before it changes
  anything and closes it only when a run completes. While the record names the key in use, or
  cannot be read, `serve` leaves the key's rotation date as it was and logs a WARNING. A key changed
  with no `rotate-key` still stamps. **A run that skips an uploaded file no longer rolls the audit
  chain**, so the prior key can still be made active again to back out. **The upload pass opens
  only a regular file of a size an upload can be.** A FIFO no longer blocks it, a symlink is neither
  followed nor a skip, and a huge file is a skip rather than an abort. Its log now says whether the
  key a skipped value names is configured. See [PHI.md](../docs/PHI.md). (`BACKLOG #3737`)
