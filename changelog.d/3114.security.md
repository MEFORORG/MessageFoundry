- **A label spelled with a fold character as its first letter now stops a plain value.** Under a
  `MEFOR_*` label in the shipped log scrub, and under every label in the support bundle, a value
  ran on over a later quoted label whose keyword began with a character Python's case-insensitive
  matching reads as an ASCII letter (for example U+017F in `secret`), and would print that label's
  value. The value walk now folds case on its tokens in every pattern. Measured against the
  previous code on about 1.45 million synthetic lines: no value prints that it hid. The support
  bundle keeps its own copy of the credential patterns: the shared pass alone still prints values
  the copy hides on lines whose label prefix starts with a fold character. (`BACKLOG #3114`)
