- **A label spelled with a fold character as its first letter now stops a plain value.** Under a
  `MEFOR_*` label in the shipped log scrub, and under every label in the support bundle, a value ran on
  over a later quoted label whose keyword began with a character Python's case-insensitive matching
  reads as an ASCII letter (for example U+017F in `secret`), and would print that label's value. The
  value walk now takes each such character as a token of its own and checks for a label in front of
  it. Such a label now reads as its ASCII spelling does, so the cascade shapes pinned as open defects
  in `secretscrub.py` print on it as they do on the ASCII line. The support bundle keeps its own copy
  of the credential patterns: the shared pass alone has not been shown to print nothing the copy
  hides. (`BACKLOG #3114`)
