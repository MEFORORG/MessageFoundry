- **The session reconciler counts a referral over the lookups it sent, and strikes an id-less row
  on every pass.** A directory row with no `objectGUID` is judged without a lookup, so no referral
  can answer it. The referral's `auth.ad_reconcile_referred` audit row now carries the `asked`
  field in place of `probed`, and that row, the referral's latched message and its
  `ad_reconcile_aborted` alert count only the lookups the pass sent. The breaker's own alert still
  counts every account it judged. Such a row is also struck now on a pass that is a directory
  outage or got only referrals, as on any other pass. Such a pass still revokes nothing, so the
  row's sessions end at the first pass after it that is not aborted, and only at their own expiry
  while every pass aborts. Its revocation still counts toward the mass-revoke breaker, as before.
