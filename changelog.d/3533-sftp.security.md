- **An SFTP password login would no longer trust a host key the escape accepted for another
  login.** Under `MEFOR_ALLOW_INSECURE_TLS`, a key-only login accepts an unknown host key. paramiko
  also saved that key into the connection's `known_hosts` file. A password login naming the same
  file then trusted that server and sent it the password, though it never takes the escape. The
  connector now only reads `known_hosts` and never writes it. The accepted key is pinned in memory
  for the connection's later logins, so a changed key is still refused until a restart. See
  [CONNECTIONS.md](../docs/CONNECTIONS.md). (`BACKLOG #3533`)
