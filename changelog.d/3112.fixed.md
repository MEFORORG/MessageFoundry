- **The delta CRL refusal now gives both OpenSSL rules, and corrects the 0.5.0 entry's reason.**
  The 0.5.0 entry for `BACKLOG #299` says OpenSSL reads a delta CRL as complete. That holds only
  before openssl/openssl PR 31044, released in at least 3.0.22, 3.4.7, 3.5.8, 3.6.4 and 4.0.2.
  From that fix on, OpenSSL rejects a delta as a complete CRL, so it drops the revocations only the
  delta lists. Either way a revocation is lost, so the engine still refuses a delta CRL, and the
  refusal text now states both rules. Give base CRLs only. (`BACKLOG #3112`)
