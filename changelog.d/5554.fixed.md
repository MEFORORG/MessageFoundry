- **The `--env` help on `validate`, `graph` and `dryrun` says what the flag does there.** It said
  the flag selected the environment's values, but those commands use it only for the value-file
  check under `--project-root`, and without `--project-root` it has no effect. They load no `env()` values, resolve no `env()` reference and
  run no posture check; the help now says so and points at `check --env`, which does. ADR 0050
  carries a correction note saying the same. (`BACKLOG #5554`)
