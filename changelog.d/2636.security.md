- **A credentialed FTPS hop with `tls_check_hostname = false` is refused at construction, as SMTP
  refuses it (vault BACKLOG #2636).** With the name check off, any certificate that chains to the
  trust anchor is accepted whatever host it names, so the FTP login would go to a peer whose
  identity was never established. A `username` or `password` on such a hop now raises at build, in
  both directions, with no escape variable or posture to unlock it. The key is reachable only from a
  hand-built `ConnectionSpec`; `Ftp()` and `connections.toml` do not expose it. A hop with no
  credential keeps the WARNING. See [SECURITY-LOOSENING.md](../docs/SECURITY-LOOSENING.md).
