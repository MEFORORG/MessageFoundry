- **Three more routes from a codec error to a log line are closed.** An exception whose own
  `__str__` or `__repr__` printed a dunder-named slot, an attribute of a plain exception it held,
  or its own `__cause__` or `__context__` would have printed the character or byte a codec could
  not handle, which can be message content. Such an exception now prints as its class and a fixed
  note in a traceback, as a log argument and in `safe_exc()`. One whose method is its own Python
  code therefore loses its message whenever it is raised from a codec error or while one is being
  handled; a builtin exception, and one whose `__str__` and `__repr__` are `BaseException`'s own,
  keeps its message. A bare `UnicodeError`'s traceback again prints the notes that are plain
  text, which the earlier fix had dropped with every other note. (`BACKLOG #3340`)
