- **The `[alerts]` send timeouts, cooldowns and SMTP port load only in range.** `webhook_timeout`
  and `email_timeout` must be above 0 and at most 300 seconds, `realert_seconds` 0 to seven days, a
  rule's `cooldown_seconds` above 0 to seven days, a rule's `min_oldest_seconds` 0 or more, and
  `email_smtp_port` 1 to 65535. Infinity and NaN are refused for each float. A value out of range
  is refused at load, where before it loaded and broke the alert path at send time; an infinite
  cooldown, for one, silenced every repeat alert. Each timeout bounds each socket wait, not a whole
  send. (`BACKLOG #5770`)
