- **A Handler can no longer edit a code set's shared rows.** A multi-column CSV row, a nested TOML
  table or a TOML array returned by `translate`, `[]` or `get` was the stored object itself, so an
  edit to it changed the table for every later message until reload. Those values are now read-only
  once loaded, and an edit raises `TypeError`; `copy.deepcopy(row)` gives a copy that can change.
  See [CODESETS.md](../docs/CODESETS.md). (`BACKLOG #5897`)
