- **A reconciler revocation that ended no session and changed no role is audited but not alerted.**
  In the shipped code, two reconcilers on one store could both revoke one account. Each wrote a row
  and raised an `ad_session_revoked` alert, and for any reason but a scope change each sent the
  user a notice, although the second ended nothing. Now such a revocation still writes its
  `auth.ad_session_revoked` row, with `sessions: 0`, but raises no alert and sends no notice (owner
  ruling 2026-10-16, "audit always"). If both reconcilers read the old roles before either writes
  them, both still report. If the first reconciler's pass ended before it alerted, the account now
  pages nobody. Vault BACKLOG #3085, item 2.
