- **A reconciler revocation that ended no session and changed no role is audited but not alerted.**
  In the shipped code, two reconcilers on one store could both revoke one account. Each wrote a row,
  raised an `ad_session_revoked` alert and sent the user a notice, although the second ended
  nothing. Now such a revocation still writes its `auth.ad_session_revoked` row, with
  `sessions: 0`, but raises no alert and sends no notice (owner ruling 2026-10-16, "audit always").
  If both reconcilers read the old roles before either writes them, both still report. Vault
  BACKLOG #3085, item 2.
