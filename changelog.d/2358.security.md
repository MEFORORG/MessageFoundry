- **A trust-anchor refusal and its log lines now quote the anchor path with `repr`.** A newline or
  an escape byte in a configured anchor path used to reach the refusal text and the log raw, so one
  refusal could print as two lines. The suggested fix commands keep their own shell quoting. A
  Windows path now prints with doubled backslashes, as the pin-mismatch refusal already did.
  (`BACKLOG #2358`)
