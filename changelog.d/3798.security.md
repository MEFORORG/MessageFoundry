- **A released purge now re-reads every refusal the purge route makes, and an unknown scope no
  longer purges everything.** Before this, a purge released with no graph loaded skipped its checks
  and cancelled the outbound's queue, and any stored scope other than `top` was read as `all`. The
  release now cancels nothing when no graph is loaded or the outbound has left the graph, and its
  `approval.approved` row records the same text the route would answer. That text replaces the
  former short skip reasons, such as `outbound running`. A stored scope that is neither `top` nor
  `all` answers 422 and moves the request to `failed`, because no operator action can clear it.
  (`BACKLOG #3798`)
