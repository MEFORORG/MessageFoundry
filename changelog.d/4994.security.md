- **An empty body a keyless run left on a keyed store can be delivered.** A keyed open under
  `[store].allow_unmarked_ciphertext` now seals a live empty queue row on a surface that is
  already sealed, with the run's plaintext, so the row is delivered as an empty body instead of
  dead-lettering with an `integrity_drift` alarm. Without the opt-out the blank stays refused, as
  before. See [SECURITY-LOOSENING.md](../docs/SECURITY-LOOSENING.md). (`BACKLOG #4994`)
