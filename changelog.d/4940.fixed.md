- **`rotate-key` fails when the configured uploads directory is not there.** A missing
  `[store].uploads_dir`, such as one on a volume that is not mounted, read as zero uploads, so the
  run printed OK, stamped the key's rotation date and closed the rotation record while every upload
  behind it could still be under the prior key. The run now ends PARTIAL and exits 1, writes no
  stamp, and leaves the record open, as a skipped upload does. The uploads directory is created on
  the first upload, so a site that set `uploads_dir` and never stored an upload has none either:
  create it, empty, and re-run. An empty directory, or no `uploads_dir`, still completes. See
  [PHI.md](../docs/PHI.md). (vault `BACKLOG #4940`)
