- **OIDC sign-in refuses an id_token whose `azp` names another client, whatever its audience
  count.** The check used to run only on a token with more than one audience. A malformed `aud`
  (an array with a non-string or empty element, or an empty string) is refused too, even when it
  also names the configured client. Both are stricter than OpenID Connect Core requires.
  (`BACKLOG #5339`)
