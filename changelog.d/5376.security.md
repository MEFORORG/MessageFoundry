- **Startup attestation reports an emptied web console as drift, and counts a file only once it is
  read.** A loaded console whose every file was deleted, or swapped for a FIFO or socket, would have
  been reported as attested-nothing. Each of its `RECORD` rows is now `missing` drift when the loaded
  package is the directory that `RECORD` describes. On either arm, an attested file that fails to
  open is drift and is no longer counted as checked. When either shape leaves no file compared, the
  pass carries the new `unattested_reason` value `no_file_read_under_install_root`. A package loaded
  from elsewhere keeps `no_attested_file_under_install_root`. (vault `BACKLOG #5376`)
