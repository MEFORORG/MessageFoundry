- **Startup attestation reports an emptied or linked-out package as drift, and counts a file only
  once it is read.** The read-back of `RECORD` rows that no listed file matched still runs whenever
  a listed file sits under the install root. It now also runs when the loaded package's directory
  is, or links to, the one `RECORD` describes. So a loaded web console whose every file was deleted,
  or swapped for a FIFO or socket, is `missing` drift for each row instead of attested-nothing. So
  is a console or engine package directory swapped for a link out of the install root. The console
  walk also names a directory it cannot list as drift. On either arm, a file that fails to open is
  drift and is no longer counted as checked. A pass that compared nothing but ran the read-back
  carries the new `unattested_reason` value `no_file_read_under_install_root`. (vault
  `BACKLOG #5376`)
