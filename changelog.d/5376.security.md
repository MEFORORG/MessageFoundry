- **Startup attestation reports an emptied package as drift, and counts a file only once it is
  read.** A loaded web console whose every file was deleted, or swapped for a FIFO or socket, would
  have been reported as attested-nothing rather than as `missing` drift for each `RECORD` row, and an
  attested file that failed to open was counted as checked. Both arms now read back the unmatched
  rows whenever the loaded package's directory sits under the install root, and a pass that read no
  file there carries the new `unattested_reason` value `no_file_read_under_install_root`; a package
  loaded from outside the install root keeps `no_attested_file_under_install_root`.
  (vault `BACKLOG #5376`)
