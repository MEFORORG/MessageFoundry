- **A TLS list the linked OpenSSL refuses is now a named configuration refusal.** Where the
  interpreter allows it (Python 3.15), the engine sets its own TLS 1.3 suite list and signature
  scheme list on every context it builds. On an OpenSSL build that refuses either list, those
  narrowers raised `RuntimeError`, and only the LDAPS and Vault seam caught it, so any other hop
  would have failed with an unhandled error. `narrow_to_approved_suites` and
  `apply_operator_tls_ciphers` now raise `EngineTlsListRefused`, a `ValueError` naming the list and
  `ssl.OPENSSL_VERSION`. A connection's message names the connection and does not blame its
  `tls_ciphers`. OpenSSL 3.5.7 accepts both lists. (`BACKLOG #2484`)
