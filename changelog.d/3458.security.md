- **The Vault hop refuses an encrypted client key before the TLS library reads it.** hvac takes a
  client certificate from `VAULT_CLIENT_CERT`, and a key from `VAULT_CLIENT_KEY` when that is set.
  With no key file, OpenSSL read the key out of the certificate file, and an encrypted one made it
  ask for a passphrase and wait. Each new Vault connection now runs the engine's key-wrap check
  first and refuses an encrypted, refused or unreadable key with fixed text that names no path.
  An unencrypted key loads as before. (`BACKLOG #3458`)
