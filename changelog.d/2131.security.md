- **`messagefoundry check` has a new required leg, `oidc-revocation`.** With federated sign-in
  on, it fails where `serve` would refuse to start: an OIDC token or JWKS leg off this host that
  checks no certificate revocation, under an enforcing posture. It reads the same decision as
  `verify`'s `fed.idp_revocation` row. An anchor file missing on the machine running `check` does
  not fail it on its own; a file that is there and that `serve` refuses does. The lifespan now
  also seeds the built-in roles and runs the security-notice gate before `engine.start()`, so a
  first-run refusal stops startup before any connection starts. (`BACKLOG #2131`)
