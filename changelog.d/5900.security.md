- **A correct re-auth password on a session lost before its rotation lands no longer clears the
  account's lockout counters or raises a login-after-failures notice.** A session revoked under the
  ceremony, one whose stamp fails its seal, and one whose rotation fails each answer
  `session_lost`, and now leave the counters as the failures set them. On a kept session the clear
  waits for the rotation and is skipped when another leg changed the account's lockout state
  meanwhile. (`BACKLOG #5900`)
