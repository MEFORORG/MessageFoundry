# Backlog re-score 2026-08-20 -- build-state findings

Companion to the `Ranked backlog ... (re-scored 2026-08-20)` section of
[`docs/BACKLOG.md`](BACKLOG.md). **82 of the 226 open items misdescribe their own build state**:
5 where every limb has shipped, 77 where some has. The scores in the ranked table already price
only the **remainder**, so no score here is waiting on this list.

**These are not status changes and must not be applied as one.** Flipping an item's banner to
closed asserts that work landed, and that claim belongs where the work lands, under the `BACKLOG #N`
rule in `.github/workflows/backlog-hygiene.yml`. This is a worklist for that process, not a
substitute for it.

**Scrutiny was not uniform, and the difference matters when reading this.** Every *fully shipped*
claim below was attacked by a dedicated independent reader before it was recorded, because value 1
is the bottom of a 226-row table and a wrong "this shipped" removes an item from view rather than
merely mis-ranking it. That check overturned **13 of 17** claims the scoring pass had made, one from
value 1 back to value 6. The *partly shipped* findings did **not** get that second reader: they keep
a priced remainder either way, so the exposure is mis-ranking, not disappearance.
