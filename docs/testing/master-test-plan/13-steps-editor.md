## 12. Steps Editor (IDE structured view over Python Handlers)

**ID prefix:** `STEPS` · **Surface:** IDE (VS Code custom editor `messagefoundry.stepsEditor`) + CLI (`messagefoundry lens`) + infra (CI)
· **Primary risk:** a mis-projected row coordinate or a diverged webview mirror makes a byte-stable, re-parse-clean edit land on the *wrong statement* — a silent semantic change to a Handler that produces wrong clinical data on every message, with no failing test anywhere in the estate.

### 12.1 Scope & objectives

**In scope.** The BACKLOG #26 carve-out (#222, SHIPPED — `docs/BACKLOG.md:6689`): a structured Steps view over real Python Handlers via a typed action vocabulary, where **plain `.py` stays the only artifact and the only execution path**. Concretely:

- The **projection contract** — `messagefoundry lens parse [--json]` (`messagefoundry/__main__.py:374-390`, `:2770`) → `messagefoundry/lens.py:270 parse_module` / `:285 parse_source`, and its **coverage-partition invariant** (`lens.py:11-21`).
- The **rewrite contract** — `messagefoundry lens rewrite` (`__main__.py:392-404`, `:2793`) → `lens.py:1406 rewrite_module` / `:1423 rewrite_source`, its 11 ops (`lens.py:1382-1396 _SUPPORTED_OPS`), the row-scoped byte-space splice, the F7 stale-coordinate guard (`lens.py:1533 _check_expect_src`), the re-parse gate (`:1582 _assert_reparses`) and the 100-column refusal (`:1403 _MAX_LINE_LENGTH`).
- The **typed action vocabulary** (`messagefoundry/actions.py`, 15 verbs at `:33-49`) and the **diagnostics helpers** (`messagefoundry/diagnostics.py:36 log_note`, `:50 checkpoint`).
- The **IDE half** — `ide/src/stepsModel.ts` (2,328 lines, pure model), `ide/src/stepsView.ts` (1,142 lines, the `CustomTextEditorProvider`), `ide/media/stepsWebview.js` (810 lines, the CSP-isolated webview script), `ide/src/hl7Picker.ts`, `ide/src/hl7scope.ts`, the 27-item Add palette (`stepsModel.ts:886-1003 ADD_MENU_CATALOG`), and the ADR 0103 row context menu.
- **Round-trip fidelity** (parse → edit → re-emit with no semantic loss and no formatting churn), **graceful degradation** on hand-written/unsupported code, **per-step validation**, **undo/redo**, **Steps-view ↔ text-editor concurrency**, **git diff cleanliness**, **large/deeply-nested Handlers**, and the **architectural guardrail tests** that must fail loudly if the carve-out is exceeded.
- ADRs: 0076 (vocabulary + lens), 0086 (Corepoint import, the inverse direction), 0089 (recognition-first native idioms, Phases A–E), 0103 (row context menu), 0104 §2.3 (handler message type + HL7 field picker), 0106 (Add palette), 0108 (accumulator Send fan-out), 0035 (workspace-trust exec gate), 0072 (traced dry-run, the live-value source), 0144 (security lint).

### 12.4 Test matrix

**80 rows — 78 class T, 2 class C, 0 class A; 12 of the T rows are P0 (blocking), 0 campaign-gated.**

**Row class (`Cls`).** **T** = *Test* — a falsifiable assertion with an observable pass criterion; **only T rows count toward the release gate**. **C** = *Characterisation* — produces a recorded measurement, finding or dated decision with no threshold yet; legitimate work, but it cannot fail, so it never gates a release (a C row becomes a T row the day its threshold is recorded). **A** = *Assurance* — an external engagement; blocking only for an off-loopback / production-exposure release. This chapter has **78 T, 2 C (STEPS-75, STEPS-79) and 0 A** rows; **all 12 P0 rows are T**.

**Foreign IDs carry a document prefix.** `FCP:` = a `docs/testing/FEATURE-COVERAGE-PLAN.md` gap ID, `W25:` = a WIN2025 test ID. A bare ID always means this plan's own row.

#### S4 — STEPS-38: undo/redo fidelity

**Preconditions.** As S3. A corpus Handler committed to a temp git repo so byte-comparison is against a fixed baseline.

### 12.9 Open questions

1. **ADR 0089 Phase D (helper descent) and the AC-10 marker.** Is Phase D still on the roadmap? Until it lands, is ADR 0104 AC-10's "unmodeled code present" marker **release-blocking**, and at what strictness — a per-handler badge or a per-row annotation? *Blocks:* STEPS-28..31, and the honesty of the whole Steps view on the migrated estate that motivated ADR 0089.
